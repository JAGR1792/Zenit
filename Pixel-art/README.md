# Recursos pixel art de Zenit

Fuentes originales de arte. Lo que consume el juego vive (copiado) en `frontend/public/sprites/`.

| Carpeta | Contenido |
|---|---|
| `fuentes/` | `ELEMENTOS.zip` (perros tripulación + estados de ánimo), `PERRO1.zip` (perro director animado) y `RECURSOS_2.zip` (escenas oficiales, nave transversal, sala de sistemas y sprites del Gato Jefe naranja). |
| `gato/` | `gatoJefe1.png`–`gatoJefe5.png` (frames animados con parpadeo), `icono_gato_jefe_naranja.jpg`, `gatoJefe.jpg` y `GATO.jpeg` (hoja original previa). |
| `hojas/` | `Sprites1.jpg`, `Sprites1.1.jpg`: hojas de referencia. |
| `escenarios/nave/` | Fondos de habitaciones (`cabina_mando`, `sala_sistemas.jpg`, `laboratorio`, `soporte_vital`, `puertas`) y corte transversal completo `nave.png`. |
| `escenarios/vistas/` | Vistas de Tierra y Luna (órbita baja/alta). |
| `escenas/` | Fondos de novela visual y portada: `menu_principal_bg.jpg`, `escena_inicial.jpg`, `escena_final.jpg`, Oficina de Planificación, Sala de Crisis, Hangar y Sala de Juicio. |

## En el frontend (`frontend/public/sprites/`)

- `perro/`, `elementos/`: perros y estados de ánimo (Sol, Nube, Lluvia).
- `gato/`: frames `gatoJefe1.png`–`gatoJefe5.png` para retrato animado con parpadeo del Gato Jefe naranja.
- `iconos/`: retratos enmarcados (Capitán Perro, `icono_gato_jefe_naranja.jpg`, `icono_gato_jefe.png`, ayudantes blanco y negro).
- `escenas/`: `menu_principal_bg.jpg`, `escena_inicial.jpg`, `escena_final.jpg`, Oficina de Planificación, Sala de Crisis, Auditoría de Hangar y Sala de Juicio.
- `escenarios/nave/`, `escenarios/vistas/`: fondos de habitaciones (incluida `sala_sistemas.jpg`), corte de nave (`nave.png`) y vistas planetarias.

Regla: perros = tripulación (estáticos), gatos = comité (1 jefe + 2 ayudantes).
