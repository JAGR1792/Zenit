# Zenit

Hola mundo. Proyecto base listo para desplegar en Vercel (multi-service).

## Stack
- Backend: FastAPI (Python)
- Frontend: Vue 3 + Vite

## Run backend
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Run frontend
```bash
cd frontend
npm install
npm run dev
```
